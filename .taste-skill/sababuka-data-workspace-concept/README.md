# Konsep lokal: Katalog & Ruang Kerja Data SABABUKA

Prototipe ini dibuat untuk membandingkan pola portal data publik (Jatim/Jakarta) dengan kebutuhan tata kelola internal SABABUKA. Seluruh angka dan status pada layar adalah data contoh untuk evaluasi UI, bukan publikasi resmi.

Jalankan dari root repository:

```powershell
node .taste-skill/sababuka-data-workspace-concept/serve.mjs
```

Buka `http://127.0.0.1:4174`.

Yang dapat dicoba:

- pencarian dan filter topik;
- memilih dataset untuk memperbarui pratinjau metadata;
- berpindah antara Katalog Data dan Ruang Kerja;
- tema terang/gelap;
- tata letak desktop, tablet, dan ponsel.
